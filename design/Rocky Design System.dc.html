Fixed vs flexible

Fixed

Classes, work and commitments. Solid 1 px edge on all sides plus a lock icon. Not draggable; clicking a class opens a read-only popover with “Edit class”. Rocky never moves a fixed block. If a request needs one moved, Rocky asks instead.

Flexible

Study, personal and breaks. 2 px dashed top edge plus a grip icon. Move and resize by dragging; snaps to 15 minutes. Priority shows as a dot with a text label (High / Med / Low), so color is never the only signal.
